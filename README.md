**Obsidian i18n Kor**은 Obsidian 전용으로 제작된 현지화 언어 지원 도구로, 사용자가 Obsidian의 커뮤니티 플러그인과 테마를 손쉽게 번역하고 한글화할 수 있도록 돕습니다.

## 🎯 핵심 기능 한눈에 보기 (Highlights)

- 🌳 **위지위그(WYSIWYG) 방식**：소스코드를 직접 건드릴 필요 없이, 엑셀 수정하듯 직관적으로 편집 가능
- 🤖 **동시성 AI**：요청 동시성(Concurrence), 배치 처리량 설정 가능 + 로컬 번역 캐시 라이브러리 내장
- 💰 **예상 토큰 자동 계산**：번역 실행 전에 필요한 토큰 소모량과 예상비용(위안화/달러) 예측 기능 제공
- 📦 **번역 데이터 분리 저장**：번역 라이브러리가 플러그인과 독립적으로 저장되어 플러그인 삭제, 업데이트 시에도 안전하게 유지됨

## ⚙️ 초기 설정 (Initial Setup)

### 1. 언어 모델 구성 (Ai) (🔥 필수)

[**언어 모델**]

* **API Endpoint**：모델 서비스 제공업체의 요청 경로 (예 : `https://api.openai.com/v1`)
* **API Key**：API 키
* **Model**：드롭다운으로 선택하거나 직접 입력（예 : `gpt-4o`, `deepseek-chat` 등)
* **연결 테스트**：입력 완료 후 하단의 **"연결 테스트"** 버튼 클릭 - 연결 성공 여부 체크

여러 개의 설정 프로필(Profile)을 생성하여 다양한 모델 제공 업체 간 자유 전환이 가능합니다.

### 2. 기본 환경설정 (Basis)

[**종합 설정**]

* **대상 언어**：번역할 언어 (예 : `ko`, `ko-KR`)
* **작성자 정보**：본인의 닉네임을 입력 - 이후 번역본의 작성자 인증으로 사용
* **스마트 업데이트(추천)**：이 기능을 활성화하면, Obsidian이 대상 플러그인의 새 버전을 감지했을 때 i18n 플러그인이 자동으로 콘텐츠를 재매핑하고 **기존 로컬 번역 캐시를 적용**하므로, 번역을 다시 해야 하는 번거로움을 덜어줍니다.

## 📖 핵심 기능 가이드 (Core Features)

### 🌳 1. 비주얼 AST 편집기 (Visual Editor)

이 도구는 `main.js`를 수동으로 수정하거나 복잡하게 중첩된 JSON 구조를 일일이 찾아다녀야 하는 번거롭고 위험한 작업을 없애고, 사용자 친화적인 데이터 편집 환경을 제공합니다.

* **스마트 심층 추출 (Extract)**：'리소스 관리' 메인 패널에서 번역할 플러그인을 찾아 클릭하면 엔진이 알아서 UI 텍스트를 분리하여 빠르게 추출해냅니다.
* **초고속 인라인 편집 (Inline Editing)**：오른쪽의 '번역(Translation)' 셀을 클릭해 한국어 텍스트를 입력한 뒤 커서(포커스)를 옮기면 즉시 자동 저장됩니다. 
* **다차원 검색 기능**：상단 통합 검색창을 활용해 노드 유형, 변수명, 원문, 번역문 등 다양한 항목에 걸쳐 특정 용어를 즉시 찾아낼 수 있습니다. 또한 드롭다운 메뉴를 통해 '미번역' 항목만 필터링하여 효율적으로 작업을 처리할 수 있습니다.

### 🤖 2. 고동시성 기계 번역 엔진 (AI Translation)

让大模型接管那千篇一律的体力劳动！

* **고동시성 일괄 번역 (Batch)**：에디터의 'AI 언어 모델 패널'을 이용해 보세요. 동시성(concurrency)과 배치(batch) 크기만 설정하고 '번역' 버튼을 누르면 알아서 번역됩니다.
* **비용 폭탄 방지 (Token Estimation)**：번역을 시작하기 전, 시스템이 즉시 백그라운드에서 예상 토큰 사용량과 총비용(예: `≈ ¥0.15`)을 계산하여 패널에 표시해 줍니다.**
* **로컬 메모리 캐시 시스템 (Memory Cache)**：시스템이 이전에 번역했던 용어를 인식하면, 상위 API로의 유료 호출을 차단하고 로컬에서 즉시 처리하여 지연 시간(latency)과 비용 없이 '즉각적인' 번역 결과를 제공합니다.

### 💾 3. 번역 워크스페이스 (Workspace)

* **비파괴 방식 적용 (Apply / Restore)**：적용(Apply)'을 클릭하여 번역 데이터를 원본 파일에 매핑합니다. 오류, 충돌 또는 플러그인 문제 발생 시 **'복원(Restore)'**을 클릭하여 원래 상태로 되돌릴 수 있습니다.
* **리소스 공유 (Export / Import)**：'일괄 내보내기(Batch Export)'를 통해 가벼운 한글 패치 JSON 파일을 생성한 뒤 사용자들과 공유해 보세요. 또한 '번역 가져오기'로 다른 사람의 번역 파일을 불러와 내 데이터에 즉시 통합하고 환경을 구축할 수 있습니다.

## ❓ 문제 해결 (FAQ)

### Q1: 연결 테스트 실패 또는 번역이 진행되지 않나요?
* 먼저 설정 페이지의 "Test Now(지금 테스트)" 버튼을 사용하여 정밀 진단을 실행해 보세요.
* `401` 오류가 발생하면 API 키에 불필요한 공백이 포함되어 있지 않은지 확인하세요. `429` 오류는 동시 요청 제한을 초과했거나(서킷 브레이커 작동) 크레딧이 소진되었음을 의미합니다.
* 네트워크 타임아웃: OpenAI와 같이 접속이 제한된 API를 사용하는 경우, 글로벌 프록시를 사용하거나 국내 포워딩 프록시로 변경해 보세요.

### Q2: 오류: "Plugin reload failed / JavaScript revision corrupted"
이 오류는 편집 중 원본 텍스트에서 `${variable}`이나 `\n`과 같은 코드 관련 제어 문자를 실수로 삭제했을 때 발생합니다. 해결하려면 메인 화면으로 돌아가 **"Restore(복구)"** 버튼을 클릭하세요. 시스템이 저장된 스냅샷을 사용하여 즉시 플러그인을 복구합니다.
