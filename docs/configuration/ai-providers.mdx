현재 소스 코드에서 AI 서비스 제공업체 관련 설정 항목은 **Settings → Community Plugins → I18N → Language Models**에 위치해 있습니다. 이 페이지에서는 서비스 제공업체 프로필, 로컬 연결 테스트, 그리고 `llmResponseFormat`을 관리합니다.

## 서비스 제공자 프로필 추가

| 단계 | 작업 내용 | 상세 설명 |
| --- | --- | --- |
| **1** | **언어 모델 탭 열기** | **설정(Settings) → 커뮤니티 플러그인(Community Plugins) → I18N → 언어 모델(Language Model)** |
| **2** | **서비스 제공업체 선택** | `provider` 드롭다운 메뉴에서 사용할 AI 플랫폼을 선택합니다. |
| **3** | **프로필 생성 및 전환** | 프로필(Profile) 추가, 전환, 삭제 기능을 통해 여러 설정값을 관리합니다. |
| **4** | **연결 정보 입력** | 기본 URL과 모델 정보는 자동 입력됩니다. 발급받은 API 키, 모델명, 가격 정보를 입력하세요. |
| **5** | **연결 테스트** | **'테스트'** 버튼을 클릭하여 API 연결 진단을 실행하고 정상 작동 여부를 확인합니다. |

## 현재 페이지의 주요 필드

| 항목 | 내용 |
| --- | --- |
| **URL / API Key / Model** | 이 필드들은 현재 제공자(provider) 프로필에 속하며, 각각 독립적으로 저장됩니다. |
| **priceInput / priceOutput** | 이 두 필드는 비용 추산의 기준이 되며, 단위는 백만 토큰당 CNY(위안화)입니다. |
| **llmResponseFormat** | 이 전역(global) 필드는 `Language Model` 페이지에서 설정하며, 현재 기본값은 `text`입니다. |

## 현재 페이지에서 직접 편집하지 않는 필드

다음 전역 번역 매개변수들은 AST / Regex / Theme 관련 AI 패널에서 읽고 쓰는 항목입니다.

- `llmLanguage`
- `llmStyle`
- `llmBatchSize`
- `llmConcurrencyLimit`
- `llmTimeout`
