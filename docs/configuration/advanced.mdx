여기서 '고급 설정(Advanced Configuration)'은 플러그인 내의 별도 탭이 아니라 문서 섹션들의 묶음을 의미합니다. 
현재 관련 진입점들은 다음과 같이 여러 곳에 분산되어 있습니다.

- `AST 설정` 
- `RE 설정`
- `몰입형 번역`
- `일반 설정`
- Cloud View 자체

## AST 추출 규칙

AST 추출기는 플러그인의 JavaScript를 구문 분석하고, 화이트리스트와 필터링 규칙을 바탕으로 어떤 문자열을 추출 결과에 포함할지 결정합니다.

<AccordionGroup>
  <Accordion title="astAssignments：변수 화이트리스트">
    변수 이름이 이 목록의 항목과 일치하면, 해당 변수에 할당된 문자열이 추출 결과에 포함됩니다.
  </Accordion>
  <Accordion title="astFunctions：함수 화이트리스트">
    함수 이름이 이 목록의 항목과 일치하면, 해당 매개변수 문자열이 추출 결과에 포함됩니다.
  </Accordion>
  <Accordion title="astKeys：객체 키 화이트리스트">
    객체 키가 이 목록의 항목과 일치하면, 해당 값이 추출 결과에 포함됩니다.
  </Accordion>
  <Accordion title="astRejectRe：제외 규칙">
    이 정규 표현식과 일치하는 경우 즉시 폐기됩니다.
  </Accordion>
  <Accordion title="astValidRe：보존 규칙">
    최소한 하나 이상의 보존 규칙과 일치하는 경우에만 보존됩니다.
  </Accordion>
</AccordionGroup>

## 정규 표현식(Regex) 추출 규칙

정규 표현식 추출기는 원본 텍스트를 대상으로 직접 매칭을 수행합니다.

<AccordionGroup>
  <Accordion title="reDatas：캡처 규칙">
    정규 표현식의 캡처 그룹을 기반으로 후보 문자열을 읽어들입니다.
  </Accordion>
  <Accordion title="reFlags：정규 표현식 플래그">
    **기본값：** `gs`
  </Accordion>
  <Accordion title="reLength：최대 길이">
    **기본：** `300`
  </Accordion>
  <Accordion title="reRejectRe：제외 규칙">
    특정 Regex 추출 결과를 제외하는 데 사용되는 정규 표현식입니다.
  </Accordion>
  <Accordion title="reValidRe：보존 규칙">
    특정 Regex 추출 결과를 유지하는 데 사용되는 정규 표현식입니다.
  </Accordion>
</AccordionGroup>

## Cloud 네트워크 관련 필드

<AccordionGroup>
  <Accordion title="githubProxyUrl：GitHub 프록시">
    **기본값：** `https://ghp.ci/`

    현재 `일반 설정(General Settings)`에 위치해 있습니다 (드롭다운).
  </Accordion>
  <Accordion title="defaultCloudRepo：기본 클라우드 저장소">
    **기본값：** 빈 문자열

    현재 `일반 설정(General Settings)`에 위치해 있습니다 (텍스트 입력).
  </Accordion>
  <Accordion title="cloudRepos：저장된 저장소 목록">
    이 항목은 설정 데이터에 저장됩니다. 저장소를 탐색할 때 클라우드 뷰(Cloud view)에서 읽고 쓰며, 설정 페이지에 별도의 입력 컨트롤은 없습니다.
  </Accordion>
</AccordionGroup>

## 몰입형 번역（IMT）

<AccordionGroup>
  <Accordion title="modeImt：몰입형 번역 활성화">
    **기본값：** `false`

    활성화 시, 플러그인이 일치하는 UI 요소에 대해 실시간 번역을 수행합니다.
  </Accordion>
  <Accordion title="imtPagerule：선택기(Selector) 규칙">
    이 필드는 몰입형 번역 대상에 포함하거나 제외할 요소를 지정하는 선택자(Selector) 규칙을 정의합니다.
  </Accordion>
</AccordionGroup>
